## Logo usage rule (critical)

- **Dark backgrounds** (deep teal, forest green, etc.) → use the **lime-green laurel** logo variant (`*-teal-bg.png` files here are pre-composited for teal; the underlying mark uses lime).
- **White/light backgrounds** → use the **mint-leaf `#11B87A`** laurel variant (`*-white-bg.png` files here).
- Never stretch, distort, recolor, add effects/outlines, or place on unapproved background colors.
- Minimum size: full logo/wordmark 80px height; symbol alone 20px height; favicon 16px height.
- Clear space: ~1/4 of the symbol's height/width around it; don't crowd with other elements.

## Typography

- **Cinzel** (serif) — headings, titles, display text. Weights: Bold, Regular.
- **DM Sans** (sans-serif) — body text, forms, captions, general content. Weights: 18 Regular, 24 Medium.
- Both are Google Fonts — load via `<link>`, no local font files needed.

## Tone of voice

Assured & understated, reverent & grounded, cultivated & refined, legacy-oriented & relational. Calm confidence, not "salesy." Tagline: **"Every child is a treasure."**

## Files in this folder

- `logomark-white-bg.png` / `logomark-teal-bg.png` — symbol only (crest/flame), no wordmark. Use as favicon or small-space mark.
- `full-logo-vertical-white-bg.png` / `full-logo-vertical-teal-bg.png` — symbol stacked above wordmark. Use for login pages, letterhead, vertical spaces.
- `full-logo-horizontal-white-bg.png` / `full-logo-horizontal-teal-bg.png` — symbol beside wordmark. Use for headers, nav bars, horizontal spaces (this is the one recommended for the admin dashboard header and form page headers).
